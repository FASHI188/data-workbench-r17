# 投资研究方法核心 V1

用途：承接早期交易员规则中仍有效、且不应继续依赖旧聊天/旧项目来源保存的研究方法。该文件是**按需读取的稳定方法层**，不是新对话启动包，不保存动态SHA、价格、日期、主线排名或当前任务进度。

## 1. 权威与任务路由

- 最新用户明确指令 > 项目治理/权限规则 > 本方法核心 > 历史交易员材料。
- 当前问题只回答当前问题；大盘、行业、公司质量、利润受益、当前能否买必须分开判断。
- 先锁定研究时点，再检索与计算；禁止用研究时点之后的信息解释当时状态。
- 需要完整扫描时，先扩实体/产业链，再验证关系和利润归属；不要先凭印象定结论。

## 2. 市场判断主轴：内部结构优先

默认顺序：

成交与相对均量 → 市场宽度 → ETF一级/二级信号 → 板块成交占比与扩散 → 龙头/后排承接 → 高位风险 → 新闻/催化验证 → 反证 → 冷结论。

新闻、机构观点、自媒体叙事不能替代市场内部结构。

## 3. 成交、宽度与ETF

### 成交

- 同时比较昨日、5日、10日、20日均量，不只报绝对成交额。
- `VCI_n = 当日成交额 / n日均成交额` 可作为相对成交强度特征。
- VCI、BRI、ClosePos等数值是**启发式特征，不是永久硬阈值**；优先结合近60日/120日滚动分位和市场制度变化解释。

### 市场宽度

- 至少看上涨/下跌家数、涨跌停、炸板、连板高度、高位补跌、昨日强势股溢价。
- `BRI = 上涨家数 / (上涨家数 + 下跌家数)` 可用于识别指数与个股广度背离。
- 指数强但宽度弱，优先检查权重托举；指数一般但宽度改善，关注结构性风险偏好修复。

### ETF必须拆分

一级资金代理：ETF份额变化、净申赎；可用 `份额变化 × NAV` 作为**估算净申赎代理值**，禁止表述为精确资金流入。

二级市场热度：ETF成交额、相对均量、折溢价、价格/NAV偏离。

解释原则：
- 宽基份额增加而小票/宽度不改善，优先检查护盘/权重效应。
- 宽基与成长/主题ETF共同改善且宽度扩散，才更像风险偏好修复。
- ETF成交活跃但份额不增，只能说明交易热度，不能直接等同新增资金。

## 4. 板块与个股承接

板块至少看：1/5/10/20日相对强弱、板块成交额及全市场占比、上涨覆盖率、龙头承接、后排扩散、低位补涨、高位切低位。

- 龙头强、后排不扩散：优先定义为抱团/局部强，不自动定义健康主线。
- 龙头强 + 板块成交占比提升 + 后排扩散：主线可信度提高。
- 消息利好但成交和扩散不确认：只能观察。

个股至少看：价格、成交、换手、量比、均线结构、近5/10/20日相对强弱、突破/滞涨/长上影/平台破位、融资、龙虎榜及解禁减持质押回购等事件。

可用特征：
- `ClosePos = (收盘价-最低价)/(最高价-最低价)`
- `VR = 当日成交额 / 5日均成交额`
- `RelStr = 个股涨幅 - 所属板块涨幅`

这些特征用于描述承接，禁止脱离位置、波动率、行业制度和滚动分位机械打分。

## 5. 新闻与证据

来源优先级：公司公告/财报、交易所、监管/政策原文、官方统计、基金正式披露、可靠行业原始资料 > 主流媒体二手报道 > 自媒体/小作文/截图。

每个重要消息至少过四道门：来源真实性、新旧/是否真增量、市场响应、持续性。

消息分层只能表示**证据质量/市场验证程度**，不得冒充股票评级。

列举具体公司、政策、产能、订单、涨价、客户、制裁或供需变化时，原则上“列举即验证”；证据不足就写证据不足。

## 6. 公司实体与利润桥

不能把产业链相关自动等同上市公司利润受益。必须区分：

- 上市公司直接并表
- 控股子公司并表
- 参股权益
- 贸易/代理
- 送样/验证阶段
- 已退出或历史业务
- 无法验证

利润传导至少拆：收入增量 → 毛利增量 → 归母利润增量；需要考虑良率、成本、折旧、套保、汇率、少数股东损益等反向因素。

“产品涨价/需求增长”不自动等于“公司利润增长”。

## 7. 检索完整性与停止条件

完整行业/主题扫描应覆盖核心产品、材料、设备、耗材、检测、客户和替代路线，并持续扩实体。

当连续三组相互独立的搜索/证据路径不再出现新的重要实体或关键关系时，可以停止扩池；停止扩池不等于所有事实均已验证，未验证项仍必须标注。

## 8. 买入/交易判断三道否决门

任何“现在能不能买”类结论至少经过：

1. 公司与利润真实性门：业务关系和利润归属是否成立；
2. 市场承接门：成交、宽度、ETF、板块扩散、个股承接是否支持；
3. 系统风险门：大盘、流动性、政策/宏观、事件风险是否构成否决。

任一关键门失败，不得强行给“可以买”；应明确写只能观察、当前不能买或应回避，并给出重新成立的触发条件。

## 9. 固定输出逻辑

事实/证据 → 逻辑链 → 反证/失效条件 → 冷结论 → 下一步可验证触发器。

禁止：故事先行、新闻替代资金验证、把相关公司写成利润受益、用固定历史阈值永久硬判、把估算ETF申赎写成精确资金流、用旧价格/旧主线/旧日期窗口覆盖实时事实。
